| 游戏 | 901,717 项断言、151,383 次实际更新 | 跳跃、扫掠落脚、穿屏、道具、战斗、程序路线和真实自动导航 |

渲染检查包括 576 组独立最近邻采样参考，覆盖缩放平台、子区域、镜像、裁剪、透明混合及火焰高度。整数商余递增优化前后另有 360 张完整帧逐字节相同；触摸覆盖层的缓存与直接绘制结果一致，退出弹窗不被触摸高亮覆盖。

26 张生成 PNG 与内嵌像素数组逐字节核对，包括 3DS 旋转 BGR 地址。角色可见实体足底到 y31，脚底边界为 y32，其下只有抗锯齿/弱透明阴影；平台可落脚线位于图像 y0，与游戏碰撞坐标一致。

游戏路线、输入和存档规则没有改动。历史规则与路线测试说明见 [1.0.0 记录](VALIDATION-1.0.0.md)。

## 渲染开销

- 21 张 RGBA 精灵共 228,456 B；5 张 BGR8 背景共 1,382,400 B。像素数据合计 1,610,856 B（约 1.54 MiB）。
- 背景预先转换为屏幕排列；正常尺寸直接复制，不实时计算渐变/大面积柔光。
- 缩放精灵使用整数商余推进，内层像素循环不执行动态整数除法。
- 下屏静态画面缓存为 230,400 B；触屏拖动只叠加方向高亮、箭头与光标，不重绘整套按钮与文字。
- ARM `-O2 -Wall -Wextra -Werror -fstack-usage` 检查通过。渲染最大单函数静态栈 344 B；缩放函数 104 B。渲染对象的 text/rodata 为 1,698,985 B、BSS 为 230,421 B；渲染过程不分配堆内存或大栈数组。

`tests/benchmark-render.sh` 用固定的 8 平台、2 敌人、弹幕、粒子和交换帧缓冲测量桌面 CPU 渲染，单位为每帧中位微秒：

| 主题 | 1.0.0 静态下屏 | 1.1.0 静态下屏 | 1.0.0 拖动 | 1.1.0 拖动 |
| --- | ---: | ---: | ---: | ---: |
| 晨光 | 35.708 | 82.334 | 85.386 | 89.386 |
| 暮云 | 36.054 | 79.799 | 85.121 | 88.279 |
| 星夜 | 35.985 | 69.152 | 86.501 | 77.662 |

新增层叠画面使上屏绘制开销高于旧版；触控缓存拆分将重设计初版的拖动开销从约 318～329 微秒降到 77.7～89.4 微秒。**这些是桌面 CPU 数字，不能推算实体 3DS 的帧率或输入延迟。**

## CIA 与 ARM

使用 devkitARM / libctru / 3DS tools、makerom 0.18.4 和 bannertool 编译。目标仍为旧 3DS 的 64 MB / 268 MHz 模式，2D 屏幕输出。

`packaging/verify-cia.py` 已确认：

- CIA 内代码与本次 ARM ELF 的三个 LOAD 段逐字节一致；内容与各节哈希通过。
- Title ID 为 `000400000F7A3500`，版本 `1.1.0 / 1040`，HOME 标题“涂鸦跃界”。
- 实际 ELF 使用的 25 种 SVC 均已声明，DSP 可写窗口和基本服务配置存在。
- 自制 CIA 没有官方签名，检查工具输出的三条相关签名警告符合预期。

CIA 大小：710080 B。

SHA-256：`7a90a6f4d3b4d3ea46eebd3cddc3ef37da61d5f803688afa3d683f928f3a8496`。

全部产物哈希见 [VERIFIED-BUILD.json](history/VERIFIED-BUILD-1.1.0.json)。打包脚本核对构建报告后生成 ZIP，并检查 CRC 与逐文件 SHA-256。

## 预览及边界

静态预览由生产渲染代码生成，包括标题、所有菜单、三种天空和角色状态。动态预览运行真实游戏逻辑并自动转向，240 帧 / 8 秒后高度约 1330.5，7 次普通落脚、6 颗星星，仍在游戏状态。GIF 使用共享调色板减少预览颜色闪烁；不参与设备渲染。

本版**尚未在实体 3DS / 2DS 或模拟器运行**。预览不是实机截图，桌面检查不能验收真实屏幕显示、设备帧率、声音、触摸延迟或断电保存行为。本次没有执行 FTP 传输或主机安装。

可直接覆盖安装 1.1.0 CIA；Title ID 和双槽存档路径与 1.0.0 相同。实机应确认标题、跳跃和穿屏、三主题、触屏/按键射击、HOME/合盖暂停及成绩保存。若发生崩溃，保留本包对应的 ELF 与 ARM11 dump。
