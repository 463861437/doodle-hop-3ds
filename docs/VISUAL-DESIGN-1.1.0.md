# 1.1.0 云端冒险视觉设计

这次重绘保留「涂鸦跃界」名称，把视觉主题转为云端邮差的浮岛冒险。角色、平台、背景和界面均由本项目绘制。

## 阅读顺序

上屏中央仍为 280×240 的游戏区域，边缘环绕与碰撞坐标不变。明亮、轮廓明确的近景平台表示可互动对象；低对比、淡色的远岛和云层属于背景。两侧仪表显示高度、纪录、星星和分数。

飞行员小猫以浅色身体、青绿护目镜与红围巾区分背景。角色足底仍与物理位置对齐；跳起、下落、眨眼、喷气姿态在渲染阶段选择，不改变物理判定。平台细节主要延伸到落脚面下方，避免误导落脚高度。

下屏沿用所有按钮热区，方向区、发射与暂停仍可用触屏直接操作。菜单按钮使用青绿主操作和浅色次操作，退出确认始终覆盖在顶层。

## 天空分区

| 高度 | 天空 |
| --- | --- |
| 0～1999 | 清亮蓝天与金色日光 |
| 2000～4999 | 暮色云海 |
| 5000 及以上 | 深蓝星夜 |

这是视觉主题，不改变路线生成、分数与道具规则。

## 资源与开销

`packaging/generate-assets.py` 使用 Pillow 离线绘制、超采样和缩小，生成 PNG 审阅图以及可直接编译的 C++ 资源。`art/generated/` 可单独查看原始分辨率美术。

背景预先编码为 3DS 的 BGR 列排列，标准屏幕直接复制；不在每一帧重算天空渐变与大范围柔光。精灵使用透明图像，游戏中分层绘制。下屏保留静态底图缓存，每次都复制到当前交换缓冲，再叠加触摸方向高亮与光标，避免整屏重绘和隔帧残影。

本项目使用 2D 输出；云层的景深来自层叠与视差滚动，并非裸眼立体显示。桌面性能测量仅用于回归比较，不能推算真实 3DS 帧率。

## 复现预览

```sh
python3 tests/make-preview.py
python3 tests/make-motion.py
```

这些脚本调用实际 C++ 渲染器。静态预览使用构造好的场景；动态预览使用真实游戏逻辑与自动转向。两者都不是设备截图。
