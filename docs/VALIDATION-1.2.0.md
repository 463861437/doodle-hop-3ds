## 美术与布局

- 42 张 RGBA 精灵：813,152 B。
- 6 张旋转 BGR8 背景：1,612,800 B。
- 总像素数据：2,425,952 B（约 2.31 MiB）。
- 48 张 PNG 与生成头文件逐字节一致，包含旋转背景的像素方向检查。
- 六种狐狸姿态的最后强不透明行均为 y39，脚底边界 y40；y42 及以下只有很弱的抗锯齿/阴影（峰值 alpha 8）。
- 12 种主题平台的中央落脚面从图像 y0 开始，与碰撞面一致。

已目视审阅标题、准备、游戏、喷气、暂停、结算、帮助、退出确认、左右穿屏以及三主题预览。角色、平台和敌人使用统一满幅投影；顶部徽章最后绘制；中文按钮和菜单没有截断。森林在最终一轮补强树屋、桥灯、窗格、台阶与树皮细节。

## ARM 与绘制开销

ARM 使用 `-O2 -Wall -Wextra -Werror`，并独立检查 `-fstack-usage`。渲染最大单函数静态栈 424 B，精灵缩放函数 104 B。渲染对象 text/rodata 为 2,454,620 B，BSS 为 230,421 B，其中 230,400 B 是下屏静态缓存；没有新增大栈数组或每帧堆分配。

背景、光照、按钮和纸卷材质预先绘制。标准背景直接复制，缩放精灵保留整数商余推进；触屏反馈只叠加金色描边与光标。完整边框采用九宫格绘制，避免拉伸角饰。

`tests/benchmark-render.sh` 使用相同场景和编译参数对比 1.1.0 与 1.2.0。以下为无并行构建时的串行桌面基准，每帧中位微秒：

## CIA 与发行包

使用 devkitARM / libctru / 3DS tools、makerom 0.18.4 和 bannertool 构建。目标仍为旧 3DS 的 64 MB / 268 MHz 模式，2D 屏幕输出。

`packaging/verify-cia.py` 已确认：

- CIA 内代码与当前 ARM ELF 三个 LOAD 段逐字节一致。
- 内容、代码和资源节哈希匹配。
- Title ID `000400000F7A3500`，版本 `1.2.0 / 1056`，HOME 标题“涂鸦跃界”。
- ELF 使用的 25 种 SVC 均已声明，所需服务和 DSP 可写窗口存在。
- 三条缺少官方签名的警告符合自制 CIA 预期。

CIA 大小：1107904 B。

SHA-256：`1421ad87b3feb5444bd55f75a6171bad0c3967435355e4ad5c85642b81364e67`。

完整构建记录见 [VERIFIED-BUILD.json](history/VERIFIED-BUILD-1.2.0.json)。发行脚本比对哈希后生成源码 ZIP 与安装 ZIP，核对 CRC 并附逐文件 SHA-256。

## 预览与实机边界

静态图由生产 C++ 渲染器绘制，演示数值来自构造的场景。动态预览使用真实游戏逻辑和自动转向，240 帧 / 8 秒后高度约 1330.5、普通落脚 7 次、星星 6 颗，仍在游玩；GIF 使用共享调色板减少颜色闪烁。
