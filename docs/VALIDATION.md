# 1.3.0 验证记录

日期：2026-10-25。电脑环境：macOS / Apple Silicon。项目：涂鸦跃界 Doodle Hop 3DS。

## 改动与测试

本版使用 Blender 原创建模、离线渲染的角色、场景和平台，重绘现代卡片界面，补充落地光圈与喷气尾光。3DS 运行时仍使用 2D 图片。游戏物理、控制、主循环、音频和存档五份实现与保存的 1.2.0 源码包逐字节一致。

以下检查全部通过；C++ 检查启用 AddressSanitizer / UndefinedBehaviorSanitizer 与严格警告。可用 `./check.sh` 统一运行。

| 检查 | 结果 | 覆盖范围 |
| --- | --- | --- |
| 游戏 | 901,717 项断言、151,383 次实际更新 | 扫掠落脚、左右穿屏、路线可达性、真实导航、道具、战斗和分数 |
| 输入与存档 | 56 项 | 触控热区、摇杆/按键、双槽保存与损坏恢复 |
| 音频 | 49 项 | 初始化/分配失败、队列、资源清理与无声回退 |
| 实际主循环 | 12 场景、458 项 | 实体键/触屏、HOME/合盖、暂停、退出、保存与输入释放 |
| 渲染 | 161 帧、2,651 项 | 完整投影、精确精灵合成、穿屏、HUD、三主题结构、缓存、光圈、文字对比与缓冲区保护 |

保留 1,368 组独立采样参考，覆盖裁剪、镜像、缩放、透明混合和 UI。角色尾巴使可见外框不对称，因此定位检查使用独立完整 RGBA 合成参考，在三个世界横坐标逐像素比较，避免把可见外框中心误当成脚底锚点。

新增检查确认：光圈随有效落地状态显示并正确穿屏；零值、负值、NaN 和无穷值不会绘制错误光圈；下屏缓存与直接绘制逐像素一致，持续增长的成绩和触摸反馈不会破坏静态缓存。

## 美术、布局与资源

- 22 张高分辨率三维渲染 PNG，由 `packaging/render-modern-3d.py` 创建模型、材质、灯光与相机，以 bpy 4.5.3 / Cycles 32 samples 渲染。
- 39 张运行时 RGBA 精灵：754,528 B；6 张旋转 BGR8 背景：1,612,800 B。
- 总像素数据 2,367,328 B，约 2.26 MiB，比 1.2.0 少 58,624 B。
- 45 张运行时 PNG 均与资源清单哈希、尺寸和编译头文件逐字节一致，包括背景旋转和 BGR 顺序。
- 角色图片 40×44，脚底锚点 (20,40)；平台画布 80×24，落脚面从中央 y0 开始，细长圆角平台的实际可见高度约 9～11 像素。
- 物理世界宽度仍为 280 单位，水平投影至完整 400 像素；下屏仍为 320×240，触摸热区保持一致。

已目视审阅标题、准备、游戏、喷气、暂停、结算、帮助、退出确认、左右穿屏和三主题预览。森林浮岛、天空城和晶谷使用不同的建筑与景观结构。平台保留类型颜色、裂纹和推进器特征。帮助页使用局部深色底板，避免全屏压暗背景。

独立渲染检查采样实际文字笔画及相邻底色：帮助页副标题/底部说明和发射按钮“长按”达到至少 4.5:1，大标题达到至少 3:1。按钮与 HUD 主文字已检查对应底色的对比度。中文菜单无截断。

## ARM 与绘制开销

ARM 渲染器独立使用 `-O2 -Wall -Wextra -Werror -fstack-usage` 编译通过。最大单函数静态栈 480 B（1.2.0 为 424 B），精灵缩放函数 104 B。渲染对象 text/rodata 为 2,453,982 B，data 为 0，BSS 为 230,421 B，其中下屏静态缓存占 230,400 B。没有新增每帧堆分配或大栈数组。

三维光照预先渲染为图片；背景直接复制，缩放精灵保留整数推进，下屏保留静态缓存。新增特效仅叠加少量光圈线段与尾光精灵。

同一编译器、相同场景与参数，提前编译两份二进制后串行计时；每组预热 40 帧，再测 5×200 帧。下表为每帧中位微秒，完整范围见 [原始基准记录](render-benchmark-1.3.0.txt)。

| 区域 | 版本 | 静态下屏 | 连续拖动 | 上升/创纪录/加分/拖动 |
| --- | --- | ---: | ---: | ---: |
| 1 | 1.2.0 | 85.132 | 89.122 | 78.023 |
| 1 | 1.3.0 翡翠浮岛 | 84.985 | 77.757 | 77.655 |
| 2 | 1.2.0 | 78.750 | 78.940 | 78.468 |

## CIA 与发行文件

使用 devkitARM / libctru / 3DS tools、makerom 0.18.4 和 bannertool 构建成功。目标为旧 3DS 的 64 MB / 268 MHz 模式，2D 屏幕输出。

`packaging/verify-cia.py` 已确认：

- CIA 代码与当前 ARM ELF 三个 LOAD 段逐字节相同。
- 内容、代码与资源节哈希匹配。
- Title ID `000400000F7A3500`，版本 `1.3.0 / 1072`，HOME 标题“涂鸦跃界”。
- ELF 使用的 25 种 SVC 均已声明，所需服务及 DSP 可写窗口存在。
- 三条缺少官方签名的警告符合自制 CIA 预期。

CIA 大小：1,072,064 B。

SHA-256：`f64b0c8ced8b286a0012c429d17bb94465255408d15190de4d31c094677a6680`。

完整构建记录见 [VERIFIED-BUILD.json](../packaging/VERIFIED-BUILD.json)。发行脚本核对当前二进制哈希，再生成源码 ZIP 与安装 ZIP，检查 CRC，并附逐文件 SHA-256。

## 预览与实机边界

静态预览由生产 C++ 渲染器绘制，演示数值来自构造场景。动态预览运行真实游戏逻辑与自动转向，240 帧 / 8 秒后高度约 1330.5、落脚 7 次、星星 6 颗，仍在游玩；GIF 使用共享调色板。

**本版尚未在实体 3DS / 2DS 或模拟器上运行。** 预览为桌面输出，尚未验证设备显示、声音、帧率、触摸延迟和断电保存。本次没有执行 FTP 传输或主机安装。

可直接覆盖安装旧版，沿用相同 Title ID 和存档路径。实机应确认平台辨识、完整穿屏、落脚、触控/射击、三主题显示、HOME/合盖暂停与成绩保存。如发生崩溃，保留本版 ELF 及对应 ARM11 dump。
