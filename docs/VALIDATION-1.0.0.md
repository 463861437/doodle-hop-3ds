## 路线与实际模拟

- 40 个随机种子的生成路线分别验证到超过 26,000 高度：主链平台为永久普通平台，相邻高度差 38～50、左右最短距离不超过 60；实际跳跃能力留有加速余量。
- 4 个种子使用真实 `Game::step`、自动转向与射击，均达到 10,000 高度。没有传送角色、跳过碰撞或修改物理；每局包括至少三次喷气拾取及喷气后再次落脚。
- 120,000 次随机输入更新检查数值、固定容量对象和游戏重新开始。
- 自动导航证明可通行，不代表真人难度、触屏手感或实机帧率已经验收。

规则参数：普通起跳速度 360、重力 780、弹簧速度 530；喷气向上速度 290，持续 1.6 秒。角色最大水平速度 160，输入有加速／制动。发射冷却 0.24 秒，子弹速度 460。高度从起始脚底位置计算，每整数高度加 10 分，星星加 100，击败怪物加 250。

平台、敌人、子弹、粒子分别使用固定容量 40 / 8 / 12 / 48，不在游戏中无界扩容。永久路线平台宽度从 58 在高度 2400 后缩至 52，特殊分支不替代主路线。

## ARM 与安装包

使用本工作区 devkitARM / libctru / 3DS tools，makerom 0.18.4、bannertool。ARM 编译开启 `-O2 -Wall -Wextra -Werror`，以旧 3DS 的 64 MB / 268 MHz 模式构建。

独立 `-fstack-usage` 检查中，游戏核心最大函数栈 384 B，渲染最大函数栈 320 B。下屏缓存为静态 230,400 B，所有角色图像和中文子集字库内嵌，无外部素材加载路径。以上是构建和源码检查，不是实机内存压力测试。

`packaging/verify-cia.py` 已确认：

- CIA 内代码与当前 ARM ELF 的三个 LOAD 段逐字节相同。
- CIA 内容、ExeFS、ExHeader 和 Logo 的哈希匹配。
- Title ID 为 `000400000F7A3500`，版本 `1.0.0 / 1024`，HOME 标题“涂鸦跃界”。
- 实际 ELF 使用的 25 种 SVC 均已声明，基础服务与 DSP 可写窗口配置存在。
- 三项没有官方签名的警告是自制 CIA 的预期结果；不代表拥有官方签名。

二进制大小、SHA-256 和完整结果见 [VERIFIED-BUILD.json](history/VERIFIED-BUILD-1.0.0.json)。发行脚本只接受与该报告哈希相同的产物，并检查 ZIP CRC、附带逐文件校验和。

## 预览与真实设备边界

`tests/make-preview.py` 使用生产 C++ 渲染代码生成摆放好的演示场景与全部界面，预览数值不是一次真人游戏记录。`tests/make-motion.py` 使用真实物理、自动转向和渲染生成 240 帧 / 8 秒动画，本次模拟结束高度约 1330.5、7 次普通落脚、6 颗星星，仍处于游戏状态。

所有预览均为桌面输出，**不是实机或模拟器截图**。本版尚未在真实 3DS / 2DS 或模拟器运行，没有测量设备帧率、声音、端到端输入延迟或断电保存表现。

安装后应确认：能进入标题、自动跳跃与左右穿屏正常、触屏和 A 射击可用、HOME／合盖后暂停、重开游戏保留成绩。出现崩溃时保留与该包对应的 ELF 和主机 ARM11 dump，以便定位。
