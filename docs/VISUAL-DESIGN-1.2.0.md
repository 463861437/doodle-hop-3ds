# 1.2.0 童话插画重设计

本轮采用精致童话插画方向，增加植物、建筑、奇幻地貌和材质层次。保留游戏名「涂鸦跃界」，将画面主题设为「幻境漫游」。

## 满幅上屏

上屏从中央 280 像素视窗扩展为完整 400×240 画面。物理世界仍为 280 宽，水平位置和平台宽度经统一 `400 / 280` 投影；左右穿屏周期对应 400 屏幕像素。垂直世界坐标、平台高度、起跳能力、碰撞与路线生成保持原规则。

高度、星星和分数显示在顶部紧凑徽章中。背景与物件先绘制，HUD 最后覆盖，避免装饰侵入数字区域。主角扩为 40×44 图像，脚底锚点为图内 (20, 40)；帽、耳和尾巴属于轮廓装饰，中心身体对应原有碰撞区域。

## 三套独立场景

| 高度 | 主题 | 场景结构 |
| --- | --- | --- |
| 0～1999 | 森林树屋 | 树冠、树干、树屋、吊桥、藤蔓、蘑菇与暖阳 |
| 2000～4999 | 空中钟城 | 钟楼、尖屋顶、拱桥、机械与暖霞 |
| 5000 及以上 | 月光水晶遗迹 | 月轮、断柱拱门、晶簇、发光植物与薄雾 |

三个主题分别绘制建筑和地貌，使用各自的平台材质、敌人外观、装饰与环境小粒子。普通、移动、碎裂与一次性平台的规则始终一致；细节向落脚线下方延伸。

远景形成世界轮廓，中景建筑和植被丰富场景，近景角色与平台保持较明确的边缘和对比。持续移动的装饰数量受限，保留游戏落脚点的可读性。

## 双屏界面

下屏使用纸卷、绒布、木纹与黄铜装饰，菜单和操作面板保持同一画风。触控热区与旧版相同，仍可以用方向键、摇杆、按键或触摸完成所有操作。

复杂按钮和面板离线绘制。Playing 下屏使用静态缓存，触摸高亮与光标独立叠加；实时高度、得分与本局星星只显示在上屏。菜单仍显示最高纪录与累计星星。

## 资源与复现

`packaging/generate-assets.py` 绘制并超采样素材，保存 `art/generated/*.png` 和内嵌 C++ 像素数组。背景预编码为 3DS 旋转 BGR8 格式。大范围光照、渐变和材质不在每一帧重算。

```sh
python3 packaging/generate-assets.py /absolute/path/to/NotoSansSC.ttf
python3 packaging/generate-font.py /absolute/path/to/NotoSansSC.ttf
python3 tests/make-preview.py
python3 tests/make-motion.py
```

预览调用实际 C++ 渲染器。静态预览为摆放好的场景，动画为真实游戏逻辑加自动转向；两者均不是实体设备截图。本作仍使用 2D 显示。
